🛠️ Technologies & Tools Used
Data Architecture: Medallion Architecture (Bronze, Silver, Gold), Star Schema Dimensional Modeling.

Database & SQL: SQL Server / PostgreSQL (Relational Database Management).

ETL / Data Processing: Python (Pandas), SQL Queries, Batch Processing.

Visualization & BI: Power BI, Enterprise Reporting.

Version Control: Git & GitHub.

🚀 Key Features & Engineering Practices
Idempotent Pipelines: Designed with safe load strategies (Truncate & Insert, Batch processing) to handle repeatable runs.

Data Governance & Cleansing: Strict schema enforcement and standardization applied in the Silver layer.

Optimized Analytical Performance: Dimensional modeling in the Gold layer enables fast aggregations and slicing for BI dashboards.
